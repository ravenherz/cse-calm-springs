# theme-thymeleaf-modern

Default public skin. Packed as `modern.csetheme` and copied into the WAR.

## Does

- Thymeleaf `index.html`, layout CSS, and color schemas (`linen`, `chalk`, `atelier`, `midnight`, `studio`).

## Does not

- Activate itself. Theme install and the active-theme setting stay in `cse-themes` and the WAR.
- Provide the admin desk. That is `app-admin`.
